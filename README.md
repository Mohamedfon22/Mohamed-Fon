# MOHAMED FON
مشروع متجر عربي على Cloudflare Workers + D1.

## خطوات الإعداد
1. أنشئ قاعدة D1 باسم `mohamed-fon-db` في Cloudflare.
2. انسخ Database ID وضعه بدل `REPLACE_WITH_D1_DATABASE_ID` في `wrangler.toml`.
3. من Cloudflare Workers أضف Secret باسم `ADMIN_PASSWORD` واختر كلمة مرور قوية بنفسك؛ لا ترسلها لأحد ولا تضعها في GitHub.
4. طبّق ملف `migrations/0001_initial.sql` على قاعدة D1.
5. انشر Worker واربط مجلد `public` كـ assets وفق إعداد `wrangler.toml`.

## الوظائف
- عرض المنتجات وإضافتها إلى السلة.
- حفظ بيانات العملاء والطلبات وعناصر السلة.
- نموذج صيانة يحفظ الطلبات ويرسل تفاصيلها إلى واتساب `01067936382`.
- لوحة إدارة لإضافة المنتجات وتحديث حالات طلبات الصيانة.

## ملاحظات
- يلزم إعداد D1 والسر والنشر قبل تشغيل الموقع.
- صور المنتجات حاليًا تضاف كرابط صورة؛ لم يتم إعداد R2 لرفع الصور.
- بعد تسجيل الطلب يفتح واتساب برسالة جاهزة، وعلى العميل الضغط على إرسال.
